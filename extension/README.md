# 售后助手 Chromium 插件

## 使用

1. 先运行上级目录的 `Start-Agent.ps1`，本地服务需保持运行；未配置模型时仍可进入本地模式。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载解压缩的扩展程序”，选中本目录 `extension`。
4. 打开普通网页后，悬浮球会自动出现。点击球体打开侧边栏对话；拖动球体可调整位置，悬停后可点右上角关闭。隐藏状态和位置按网站保存；从工具栏打开侧边栏后可点“显示悬浮球”恢复。
5. 球左下方两个小椭圆分别设置页面权限和协助模式。选择“允许手动读取当前页文字”后，还要在侧栏主动点击“读取页面文字”；内容会显示在可编辑文本框中。

页面权限选择仅控制功能是否可用，不会自动读取网页。读取范围仅为当前标签页可见正文，不读表单控件值、Cookie、页面存储或其他标签页。未勾选单轮同意时，输入只发送到本机服务；勾选后，描述和文本框内容发送至阶跃星辰。当前不会模拟点击网页、填表或提交。

## 权限与兼容性

悬浮球自动显示需要在 `http` 和 `https` 普通网页加载一个轻量内容脚本，因此浏览器会显示扩展可在网站上运行的权限提示。插件脚本只创建悬浮球界面；页面文字读取仍需要用户先开启对应选项，再在侧栏主动点击。浏览器内部页面、扩展商店页面和受限网页不能运行内容脚本。

支持 Chrome 116+ 与支持 Side Panel API 的 Chromium 浏览器。扩展仍处于开发原型阶段，模式选项是交互偏好；网页自动点击、真实平台适配、语音合成和全套售后技能尚未接入。任务记录以未加密形式保存在本机，建议先用虚构资料试用。

## 打包

`售后助手-Chromium插件-MV3.zip` 为未签名源码包。解压后以“加载解压缩的扩展程序”使用；此包不是 Chrome Web Store 发布包。
