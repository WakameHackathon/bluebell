# 售后助手 Agent（本地集成原型）

这是售后流程 Agent 的可运行本地原型：主 Agent 对话、任务续接、14 项 Skill 注册与调用、结构化 Skill 结果、SQLite 会话记录、经用户逐轮同意后调用的阶跃星辰 OpenAI 兼容接口，以及自动显示悬浮球的 Chromium 插件。

## 启动

```powershell
cd aftercare-agent
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
.\Start-Agent.ps1
```

打开 `http://127.0.0.1:8766`。未配置密钥或未勾选单轮传输同意时，只使用有限的本地回复；勾选后，本轮描述与选填页面文字会传给阶跃星辰模型处理。不要把真实密钥写入代码、聊天记录或提交版本库。先前曾粘贴到聊天中的密钥应到服务商后台轮换后再使用。

## 当前范围

- 14 个 Skill ID 都进入工具路由注册表；输出采用接口统一 envelope，尚未实现各 Skill 的完整产物结构，因此不伪造完整产物，未完成分析返回 `data: null`。
- Chromium 插件在普通 HTTP/HTTPS 网页显示悬浮球；用户可以拖动、隐藏并恢复。读取当前页面文字需先在球的权限菜单开启，再于侧栏主动点击读取；内容作为不可信页面证据单独传给模型。
- 单任务只处理一件商品；任务与消息存入本地 SQLite，目前未加密；试用请使用虚构信息，不要输入真实订单号、地址、证件或支付资料。
- 模型无法连接时使用保守的本地回复。
- 14 项 Skill 的完整业务推理/产物尚未实现；网页自动操作、真实平台适配、文件上传/转换、ASR/TTS、授权票据、动作队列、提交核实、跨设备加密同步尚未接入。模式选项目前只记录用户偏好，不代表已能替用户操作网页。不得把这个原型演示成已经完成真实售后。

项目的 14 Skill I/O 细节仍以 `../outputs/售后Agent-Skills接口-v1/` 中的接口规范和 Schema 为基线。这里实现的是运行时接线和安全受限的首个纵向原型，不意味着所有 14 项业务能力都已完整落地。
