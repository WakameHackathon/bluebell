# 草稿核对与发送授权

阶段必须分别呈现并由相应责任方记录：

1. **草稿已准备**：本轮 Skill 输出完成；可供用户检查，不发生外部发送。
2. **用户已核对**：只表示该具体版本的事实/文字/附件经用户检查，不代表允许发送。
3. **发送待授权**：执行层在动作前展示已核实渠道、完整消息、附件清单及已知后果并取得明确、当前授权。
4. **已发送/结果未知**：仅由执行回执与台账确认。未知时先查客服会话/平台记录，不重发。
5. **客服已受理/仅已收到/已解决**：由后续页面或客服回复证据分别确认；“已收到”不是“已受理”，受理不是问题解决。

草稿内容、渠道、附件、商品或关键事实改变后，旧核对和授权失效；已发送消息不能用旧授权再次发送。含糊“好/嗯”、沉默、语音识别不清不是发送授权。发送授权和 confirmation_ref 由宿主/执行层产生和验证，本 Skill 不产生、不请求假凭证，也不声称已发送。渠道无法验证时允许输出供用户自行复制的草稿，但清楚注明尚未发送。
