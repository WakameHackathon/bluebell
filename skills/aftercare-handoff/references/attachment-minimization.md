# 附件最小化

每个拟附材料都要同时满足：来自当前 task 内获准 EvidenceBundle 的真实引用；与当前未解决问题直接相关；内容仍有效且能支持所述点；用户有权核对；不含无关敏感资料，或应先由 `aftercare-evidence` 制作获准的派生副本。优先一两件最直接证据，区分必需和可选并说明原因。不要因文件存在就附加，也不要推断 EvidenceBundle 所有文件都获准远程发送。

完整支付记录、完整聊天/订单历史、完整地址、电话、账号、证件和家庭成员资料通常不应进入普通摘要/附件；若争议确需某个字段，最小化说明并交用户/宿主核验适用范围。拒绝把本地读取许可当作发送许可。不编辑原始证据；需要遮挡时交 evidence Skill。引用丢失、任务不符或内容变化时重核；不把失效引用留在 `file_refs`。无合适材料时 `file_refs: []`，正文明确证据缺口，不用措辞强度补足。
