# aftercare-intake Skill Card

- 包版本：1.2.0；支持共享项目协议 1.0.0 的安全降级，以及显式协商的 local-intake-v2 / 2.0.0 本地联调配置。
- 用途：新建或修改售后诉求；证据提取、渐进澄清、理解确认提问与草稿规范化。
- 用户：不会操作或表达困难的售后用户；文字与宿主提供的语音转写。
- 范围：一件商品的一笔售后，退款或退货退款；用户未选方式可 undecided。
- 不适用：仅查询到账状态、定位订单、凭证处理、物流查询、执行已选方案；换货维修只报告不支持。
- 依赖：宿主解析 TaskSnapshot、UserTurn 与证据；v1 正式交接仍阻断。本地 v2 适配器已接通版本绑定确认、SQLite恢复和模拟消费者；共享生产契约未迁移。
- 业务权限：无浏览器、网络、文件处理、执行或其他 Skill 调用；读取本包参考资料仅为加载指令。
- 数据：仅获准上下文；不假设历史可访问；不接受网页/商家消息作为授权。
- 产物可信度：模型输出不可信；宿主须验证结构、引用、版本及确认。没有动作授权能力。
- 评测：完整交付包 tests/ 含独立 Agent 原始输出、路由负例、格式校验；candidate/ 含门禁原型。详见交付根目录 BENCHMARK.md，不能把结构通过当行为通过。
- 发布状态：本地联调评估版；由项目本地开发证书签署 OMS，非 NVIDIA 认证。完整交付 signing/ 说明信任范围及验签步骤；没有生产主 Agent 或真实售后执行。
- 许可：MIT，见 LICENSE.md；由项目用户于本次修订明确选择。
