# 可逆探索与内容保护

仅在证据能证明以下四项时使用 reversible_explore：当前任务范围内、不会提交/外发或产生关键业务效果、不会丢失重要未保存内容、探索后能通过新观察核对变化。说明支撑这些判断的证据及退出条件，而非只写“安全”。

可考虑：展开已知只读菜单、查看同一商品详情、进入已核实只读记录页。即使称为“查看”，若控件可能接受方案或自动保存也不算可逆。高亮不改变按钮含义，不遮挡后果。

普通提示弹窗：先证明是无业务后果提示、关闭不会丢失表单，再交 interact 准备一步关闭。登录、费用确认、放弃修改、撤销申请弹窗要按用途交用户或业务核对，不能一律关闭。

刷新/返回/重新进入：先检查表单重发、已填字段、临时文件及导航离开后果。风险未知时 reobserve 或 ask_user，不能默认刷新。保护现场不意味着擅自复制隐私或保存到新位置。

已发出或可能发出的业务效果优先查记录；不能借“可逆探索”再选择文件、发送、撤销或预约。确认原请求无效果以后也只可能重新准备，仍须新证据、当前授权与执行层允许。
