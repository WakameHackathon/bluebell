# 材料检查与补充

先读取当前要求的来源、适用商品/方案与观察版本。必需来自明确平台证据；条件性要求先核实条件成立与否，未知则 uncertain；建议始终标为可选；尚不清楚是否需要则请求观察。不保证“这些一定通过”。不推断退款资格。

逐项判断相关性、可读性、必要上下文、真实格式/字节大小/数量、与用户陈述冲突、无关隐私。说明理由必须能追溯到文件、用户陈述或页面证据。脚本只读元数据不等于看懂内容；未经视觉或获准本地工具核验关键部位，清晰度和商品匹配保持未知。

| 当前依据 | 本轮处理 |
|---|---|
| 页面最大 5MB，文件未测量 | 大小 uncertain，不说超限；先用获准本地工具测量 |
| 实测超过已核实上限 | 获准后压缩副本；测量尺寸/格式/字节；关键内容重新查看，尚未看清就 uncertain |
| 照片模糊 | 说“这张看不清杯口”，不说没有裂纹 |
| 不同商品或无法确定 | 暂不关联，问这是否本次商品；明确目标冲突回订单确认 |
| 用户说完好、图中似有裂纹 | 分别保留陈述与可见现象，询问关键差异，不判断责任 |
| 条件性外包装要求，用户说没有 | 记录缺失/条件待核实，请主 Agent 查可用替代，不反复索取 |
| 裁剪可能删聊天前后文 | 保留原样，不能只截有利部分 |
| 地址看似无关但页面需核验收件标签 | 先核对必要字段，不自动遮挡 |

补充指导应是具体单步，如“页面要求看到完整商品，可以补一张整体照片。拍不到也可以告诉我。”用户回答不知道时换成简短选项；不能补拍就停止同项追问，保留未解决记录。安全故障不要求重新通电、拆机或重复危险动作。需要转客服由主 Agent 决定，本 Skill 不发送。

说明示例：“用户陈述收到后发现杯口有裂纹；所附照片中杯口可见一条裂纹。拍摄时间未核实。”只有真的看见才写直接观察；照片未读则只写用户陈述。逐句证据在宿主拟议 assessment 中记录；v1 不能机器绑定时不声称已完整可追溯放行。用户纠正为“是划痕，不是裂纹”，更新陈述并保留图像判断的不确定，不能维护旧结论。
