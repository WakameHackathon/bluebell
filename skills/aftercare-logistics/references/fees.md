# 费用与保障

分别记录：确定报价、预计价格、计费规则、可能额外费用、未知费用、运费险/补贴。引用当前商品本次服务的页面证据及有效时段；其他订单价格或通用经验不能补齐。运费险可能有条件、额度或先付后报，不承诺全免、必报销或到账时间。

Money={currency:ISO三字母大写代码, minor_units:非负整数}；按契约的最小货币单位解析明确结构化金额，含糊原文保留未知。fee_known=false 必须 fee=null；只有当前明确的确定费用依据、币种和金额均匹配才 fee_known=true。明确免费需要明确零元证据，不能由“有运费险”推导。

v1 无费用性质字段，预计费用保持 fee_known=false/fee=null，user_message 可据证据解释这是估算和未知部分，关键机器状态另列修订，不藏进自由文本后让执行器解析。预计不是解析失败，也不是最终金额。计费规则/保障不等于一个 Money。重要费用缺失请求新页面证据；用户仅决定是否接受已说明的条件，不能让用户猜平台价格。

费用、附加费条件、服务或地址变化时撤销旧提案有效性，重新核对。当前包不处理付款或报销提交。
